# 🦅 FALCON BROTHERHOOD — موقع العصابة (جاهز لـ Vercel)

## الملفات
- `index.html` — الموقع العام (عرض فقط: أخبار + منظمات + إعلانات + ترقيات)
- `news.html` — 📰 صفحة البيانات الرسمية (كل بيان بصفحة كاملة + رابط `news.html?id=...`)
- `support.html` — 💰 صفحة الدعم المادي (هدف + حائط الداعمين + فورم تبرع)
- `admin.html` — 🛡️ لوحة التحكم (للإدارة فقط: النشر + الإدارة الكاملة)
- `app.js` — منطق الموقع العام
- `admin.js` — منطق لوحة التحكم
- `styles.css` — التصميم
- `vercel.json` — إعدادات النشر
- `logo.png` — **انت حطها بنفسك** (صورة اللوجو، احفظها باسم `logo.png` جنب الملفات)
- `bg.jpg` — **انت حطها بنفسك** (صورة العصابة الجماعية، احفظها باسم `bg.jpg` جنب الملفات — بتظهر خلفية الرئيسية وصفحة البيانات، ولو مش موجودة الموقع بيستخدم خلفية احتياطية تلقائياً)

## 🆕 الجديد
- **صور GIF متحركة**: ارفع GIF كصورة حسابك (تسجيل أو تغيير الصورة) — بيفضل يتحرك زي ما هو (أقل من 100MB)
- **💰 نظام الدعم المادي** (`support.html`): الدعم بفلوس اللعبة ($) — تحويل على حساب العصابة البنكي + هدف الصندوق + حائط الداعمين (برونزي/فضي/دهبي/أسطوري) — والإدارة بتأكد الدعم من اللوحة والداعم ياخد 20 XP
- **🔗 ويب هوكين مربوطين**: إشعارات الأخبار/الإعلانات/الترقيات → ويب هوك الأخبار | إشعارات التبرعات → ويب هوك الدعم (يتغيروا من اللوحة → الإعدادات)

- أول حساب = 🦅، التاني = ⚔️، التالت = 🛡️

## 🛡️ لوحة التحكم فيها ايه؟
1. 📢 نشر إعلان (عنوان + قسم + سعر + صورة + تثبيت 📌)
2. 📰 نشر خبر / بيان رسمي (يظهر في الرئيسية)
3. 📋 كل الإعلانات (حذف / تثبيت)
4. 🎖️ طلبات الترقية (قبول ✅ / رفض ❌)
5. 👥 الأعضاء (ترقية ⬆️ / تخفيض ⬇️ / حذف 🗑️)
6. 🏛️ المنظمات (عرض + حذف — مفيش تأسيس)
7. ⚙️ الإعدادات (Webhook + رابط الديسكورد + IP السيرفر)

## الدخول كإدارة
1. سجل حساب من الموقع — أول حساب = **المؤسس (الصقر 🦅)**، وأول **3 حسابات** معاهم صلاحيات إدارة 🛡️
2. افتح `admin.html` (أو دوس زر لوحة التحكم اللي بيظهر للقادة في الموقع)
3. سجل دخول بنفس حساب القائد → اللوحة تتفتح

## ☢️ تصفير الداتا
من لوحة التحكم → الإعدادات → منطقة الخطر → **تصفير الداتا كلها** (للمؤسس فقط + تأكيد مزدوج).
بيمسح كل حاجة ويرجع الموقع زي أول يوم — بعدها سجل 3 حسابات الإدارة من جديد.

## الرفع على Vercel
1. حط `logo.png` في نفس الفولدر
2. ارفع الفولدر على GitHub
3. https://vercel.com → Add New → Project → اختار الريبو → Deploy
4. الموقع + اللوحة هيشتغلوا فوراً (Static Site، بدون إعدادات)

> البيانات في `localStorage` (على جهاز كل واحد). لو عايز قاعدة بيانات مشتركة للكل قولّي وأحوّلهالك Supabase.
